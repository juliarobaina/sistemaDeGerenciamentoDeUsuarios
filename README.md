# Sistema de Gerenciamento de Usuários
<p>Neste projeto foi utilizado o XAMPP</p>
<h2>Como executar o projeto</h2>
<ol>
  <li>Clone o repositório na pasta htdocs</li>
  <li>Inicie o MySQL e o Apache</li>
  <li>Verifique se os dados das variáveis no arquivo conexaoBD.php estão corretos com as configurações do seu banco de dados</li>
  <li>Importe o arquivo gerenciamento_de_usuarios.sql para o phpMyAdmin</li>
  <li>Voce pode ter acesso ao sistema escrevendo isto na barra de endereço do seu navegador http://localhost/nomeDaPastaQueEstaOProjeto/</li>
</ol>
